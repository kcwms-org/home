- Maintained and enhanced the company's pari-mutuel wagering settlements website (ASP.NET
WebForms/VB.NET, SQL Server) under fixed-scope statements of work negotiated directly with the CFO and
CEO, including corrections and enhancements to financial reports (Contract Status, Rate Change Audit)
covering host fees, settlement-site changes, and rate structures across tracks, hubs, and outlets.
- Designed and implemented the multi-phase File Auto Load project: a Windows service built on the then-
newly-released .NET Core 2.0 (C#) that exchanged daily wagering and settlement files (TRA and aggregate
feeds) with the Egnyte cloud-storage platform and automated their ingestion and validation, replacing a
manual upload process; documented the legacy workflow and supported parallel testing through production
cutover.
- Developed cross-platform: authored the service on Linux with SQL Server running in Docker and used
GitHub Actions to build and package Windows binaries.
